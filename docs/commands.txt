FINAL BROWSERSTACK SETUP

Important:
- Keep only one BrowserStack YAML file.
- Use one platform entry in browserstack.yml for the OS/browser you want to run.
- Do not hardcode BrowserStack user credentials in repo files.
- The BrowserStack SDK reads credentials from environment variables.

PowerShell setup (local machine)
$env:BROWSERSTACK_USERNAME="YOUR_BROWSERSTACK_USERNAME"
$env:BROWSERSTACK_ACCESS_KEY="YOUR_BROWSERSTACK_ACCESS_KEY"

Then run:

# Default single target: Windows 11 + Chrome
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=windows-chrome

# Verify selection without running tests
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=windows-chrome --list

# Windows 10 + Chrome
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=windows10-chrome

# Windows 11 + Edge
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=windows-edge

# Windows 11 + Firefox
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=windows-firefox

# macOS + Safari/WebKit
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=macos-safari

# Samsung S25 + Chrome
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=samsung-s25-chrome

# Pixel 10 + Chrome
npx browserstack-node-sdk playwright test tests/orangehrm.spec.js -- --config=playwright.browserstack.config.js --project=pixel10-chrome

# Pixel 9 + Chrome

Troubleshooting
- If the SDK returns ERROR_INVALID_CREDENTIALS, the BrowserStack username or access key is wrong, expired, or not loaded into the current shell/session.
- If CLI bootstrap warns about sdk-assets.browserstack.com being blocked, that's a network/whitelist issue, but the actual rejection in this project is from invalid credentials.
- Use a valid BrowserStack account username and access key from the BrowserStack dashboard, then rerun the command above.
