Notes
- The local PowerShell runner reads the existing BrowserStack credentials from browserstack.yml.
- It rewrites browserstack.yml to one selected platform before running, so the BrowserStack run matches the chosen setup.
- GitHub workflow files are not modified, so the existing CI flow remains intact.
- Reports are generated under ./reports and ./reports/log.
- Current BrowserStack YAML contains Chrome for Windows 10, Android 15/14/16, and Safari on macOS 14; Edge and Firefox are only present for Windows 11.
