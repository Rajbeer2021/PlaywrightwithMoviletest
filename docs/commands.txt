Troubleshooting
- If BrowserStack returns ERROR_INVALID_CREDENTIALS, check the username and access key in the active PowerShell session.
- If you want a different target, update the single BrowserStack YAML or re-create it for the selected project.
- Reports are generated under ./reports and ./reports/log.
