Troubleshooting
- If BrowserStack returns ERROR_INVALID_CREDENTIALS, the username or access key is wrong, expired, or not loaded into the current PowerShell session.
- If you want a different BrowserStack target, update the single platform entry in browserstack.yml and rerun.
- Keep the reports in one folder: ./reports
